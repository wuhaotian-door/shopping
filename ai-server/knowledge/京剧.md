# 京剧

京剧，又称"皮黄"、"国剧"，是中国的国粹艺术，2010年被列入联合国教科文组织人类非物质文化遗产代表作名录。

## 形成与发展

京剧形成于清代乾隆五十五年（1790年）。当年，安徽四大徽班——三庆班、四喜班、和春班、春台班——先后进京为乾隆皇帝祝寿，与湖北汉调艺人同台演出，相互融合，吸收昆曲、秦腔等剧种的优点，逐渐形成了京剧。

京剧的发展可分为四个时期：
- **形成期**（1790-1883年）：徽汉合流，京剧雏形初现。
- **成熟期**（1883-1917年）：谭鑫培开创"谭派"，确立了京剧以老生为主的格局。
- **鼎盛期**（1917-1949年）：四大名旦（梅兰芳、程砚秋、尚小云、荀慧生）崛起，旦角艺术达到巅峰。
- **新时期**（1949年至今）：新中国建立后，京剧在剧目创作、人才培养、国际交流方面全面发展。

## 四大行当

京剧角色分为生、旦、净、丑四大行当：

1. **生** — 男性角色。包括老生（中老年男子）、小生（青年男子）、武生（会武功的男子）。
2. **旦** — 女性角色。包括青衣（端庄正派女子）、花旦（活泼少女）、刀马旦（女将）、老旦（老年妇女）。
3. **净** — 俗称"花脸"，面部勾画脸谱。多为性格粗犷或奸诈的男性角色。
4. **丑** — 俗称"小花脸"，鼻梁上抹白粉。分为文丑和武丑，多为喜剧角色。

## 四功五法

京剧表演的基本功为"四功五法"：
- **四功**：唱（演唱）、念（念白）、做（身段表演）、打（武打）。
- **五法**：手（手势）、眼（眼神）、身（身段）、法（法度）、步（台步）。

## 流派纷呈

京剧有众多艺术流派，各具特色：
- 老生：谭派（谭鑫培）、余派（余叔岩）、马派（马连良）、麒派（周信芳）。
- 旦角：梅派（梅兰芳）、程派（程砚秋）、尚派（尚小云）、荀派（荀慧生）。
- 净行：金派（金少山）、裘派（裘盛戎）。

梅兰芳是最具国际影响力的京剧大师，他创立的"梅派"艺术被誉为世界三大表演体系之一。
