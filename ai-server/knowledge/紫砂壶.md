# 宜兴紫砂陶制作技艺

宜兴紫砂陶制作技艺是中国江苏省宜兴市丁蜀镇特有的传统手工制陶技艺，2006年被列入第一批国家级非物质文化遗产名录。

## 历史渊源

紫砂壶起源于明代正德年间（1506-1521年），距今已有500多年历史。最早的紫砂工艺大师有供春、时大彬等人。供春被誉为"紫砂壶鼻祖"，他制作的树瘿壶传世至今。明代万历至崇祯年间是紫砂壶的第一个黄金时期，代表大师有时大彬、李仲芳、徐友泉。

清代康熙、雍正、乾隆三朝，紫砂壶进入第二个巅峰期。陈鸣远开创了紫砂壶花货流派，将自然界的花果树木形态融入壶艺。邵大亨是清中后期最杰出的大家，其作品"掇只壶"被誉为壶中之王。

## 制作工艺

紫砂壶的制作工艺极为复杂，主要工序包括：

1. **选料** — 宜兴黄龙山紫砂矿料分为紫泥、红泥、绿泥（本山绿泥）三大类。矿石开采后需露天堆放风化，然后粉碎、过筛、加水陈腐。
2. **练泥** — 将陈腐后的泥料反复捶打、切割，排出气泡，使泥料均匀致密。手工练泥是紫砂壶区别于普通陶瓷的关键。
3. **成型** — 紫砂壶全凭手工成型，不用模具。主要技法为"拍身筒"和"镶身筒"。制壶工具多达百余种，包括木拍子、竹篦子、明针等。
4. **装饰** — 包括陶刻、泥绘、贴花、镶嵌、绞泥等。陶刻是紫砂壶最典型的装饰手法，以刀代笔，融诗书画印于一体。
5. **烧成** — 传统使用龙窑烧制，温度控制在1150-1180℃。现代多用气窑或电窑。紫砂特有的"双气孔"结构使其透气不透水。

## 文化价值

紫砂壶不仅是一种茶具，更是集书法、绘画、篆刻、雕塑于一体的综合性艺术品。"字随壶传，壶随字贵"，一把好壶常有多位文人合作：一人制壶、一人题诗、一人作画、一人篆刻。

## 当代传承

现有一批国家级传承人和中国工艺美术大师活跃在创作一线。徐秀棠、汪寅仙、吕尧臣等大师推动了紫砂艺术的创新发展。宜兴市建有中国紫砂博物馆，每年举办陶瓷文化艺术节。
