# 桃花坞木版年画

桃花坞木版年画是中国江苏省苏州市特有的传统民间木版年画，2006年被列入第一批国家级非物质文化遗产名录。

## 历史渊源

桃花坞木版年画起源于明代，兴盛于清代雍正、乾隆年间，至今已有400多年历史。因年画作坊集中在苏州阊门内桃花坞一带，故得名"桃花坞木版年画"。它与天津杨柳青年画并称"南桃北柳"，是中国两大民间年画流派之一。

## 制作工艺

桃花坞木版年画采用木版套色印刷工艺，主要工序包括：

1. **画稿**：由画师设计并绘制墨线稿
2. **刻版**：将画稿反贴在木板上，用刻刀雕刻出线条版和色版
3. **印刷**：先印墨线版，再逐色套印各色版
4. **着色**：部分精细作品还需手工填色

## 艺术特色

- **构图**：饱满丰富，对称均衡，画面热闹喜庆
- **色彩**：以大红、桃红、黄、绿、紫、蓝等鲜艳色彩为主，对比强烈
- **线条**：线条流畅细腻，刚柔并济
- **题材**：涵盖吉祥喜庆、民间故事、戏曲人物、仕女娃娃、风俗时事等

## 代表作品

经典作品有《一团和气》《花开富贵》《福禄寿三星》《姑苏阊门图》《百子图》等，其中《一团和气》是最具代表性的作品之一。

## 当代发展

桃花坞木版年画在近现代曾一度衰落，新中国成立后得到抢救和保护。目前苏州桃花坞木刻年画社、苏州工艺美术职业技术学院等单位承担着传承与创新的使命，多位传承人致力于恢复传统技艺并融入现代设计。
