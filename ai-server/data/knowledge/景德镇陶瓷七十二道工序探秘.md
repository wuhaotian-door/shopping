# 景德镇陶瓷七十二道工序探秘

[平台链接:/news/6]
分类：陶艺

景德镇，享誉世界的"瓷都"，其手工制瓷技艺已有千年历史。从一抔瓷土到一件精美的瓷器，需要经过整整七十二道工序，道道讲究，环环相扣。

主要工序包括：采石、粉碎、淘洗、炼泥、拉坯、利坯、晒坯、刻花、施釉、烧窑等。其中，拉坯是最考验功力的环节，陶工需要在旋转的辘轳上将泥团拉成理想的器型。施釉则决定了瓷器表面的光泽和色彩。

入窑一色，出窑万彩。景德镇传统柴窑和现代气窑各有特色，窑变产生的意外之美往往令人惊叹。

如今，景德镇吸引了来自世界各地的年轻陶艺家，他们在这里建立了自己的工作室，将现代审美融入传统工艺，让千年瓷都焕发出新的活力。
