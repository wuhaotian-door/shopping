# 紫砂壶鉴赏入门：泥料、器型与工艺

[平台链接:/news/2]
分类：陶艺

紫砂壶产自江苏宜兴，以其独特的双气孔结构和优良的泡茶性能，被誉为"壶中之王"。对于初学者来说，鉴赏紫砂壶可以从三个维度入手。

首先是泥料。紫砂泥分为紫泥、红泥、绿泥（本山绿泥）三大类，不同泥料烧成后呈现不同的色泽和质感。原矿泥料制成的好壶，色泽温润内敛，手感细腻。

其次是器型。紫砂壶历经数百年发展，形成了光素器、筋纹器、花器三大类型。石瓢、仿古、西施、井栏等经典器型百看不厌。

最后是工艺。一把好壶讲究"三点一线"（壶嘴、壶钮、壶把在一条直线）、口盖严密、出水流畅、断水干脆。手工拍打成型、明针功夫等传统工艺更显匠人精神。
