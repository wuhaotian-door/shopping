# 校园非遗教育：让传统技艺走进课堂

分类：校园活动

近年来，越来越多的高校将非物质文化遗产引入校园，开设非遗选修课、成立非遗社团、举办非遗文化节，让青年学子近距离感受传统技艺的魅力。

在课程设置方面，剪纸、陶艺、刺绣、书法等非遗项目成为最受欢迎的选修课。学生们在学习技艺的同时，也加深了对传统文化的理解和认同。

在社团活动方面，非遗社团通过举办手作体验、传承人讲座、非遗市集等活动，吸引了大量学生参与。一些学生还利用新媒体平台，拍摄短视频传播非遗知识，形成了线上线下相结合的非遗传播新生态。

非遗进校园，不仅是技艺的传承，更是文化自信的培育。让年轻一代成为非遗的传承者、传播者和创新者，是非遗保护工作的重要方向。
