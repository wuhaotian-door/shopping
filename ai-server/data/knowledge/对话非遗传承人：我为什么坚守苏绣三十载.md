# 对话非遗传承人：我为什么坚守苏绣三十载

分类：传承人专访

本期专访我们邀请到了苏州刺绣传承人李秀英老师。李老师从事苏绣创作已有三十余年，作品多次获得国家级工艺美术大奖。

问：是什么让您坚持苏绣这么多年？

答：热爱。从小看着母亲和祖母在绣架前飞针走线，那种娴静的美深深印在了我的心里。苏绣不仅仅是一门手艺，更是一种生活态度。一针一线，需要耐心，需要专注，需要心静如水。

问：苏绣传承面临哪些挑战？

答：最大的挑战是人才断层。现在年轻人生活节奏快，很少有愿意花几年甚至十几年时间潜心学艺的。苏绣学习周期长，经济回报慢，这让很多年轻人望而却步。但我们也在努力改变，比如开设短期体验课，开发苏绣文创产品，让更多人先接触、再了解、最后爱上苏绣。

问：您对苏绣的未来有什么期待？

答：我希望苏绣不仅是博物馆里的展品，更能走进寻常百姓家。我们正在尝试将苏绣元素融入服装、包袋、家居用品，让传统技艺服务于现代生活。
