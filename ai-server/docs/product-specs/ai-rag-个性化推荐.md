# 个性化推荐

## 功能概述

根据用户在平台上的历史行为，推荐其可能感兴趣的非遗内容。新用户展示热门内容作为初始推荐。

## 用户场景

1. **首页推荐** — 有浏览历史的用户打开首页，看到符合自身兴趣的非遗文章、商品和活动
2. **新用户冷启动** — 无行为记录的新用户看到当前热门非遗内容
3. **详情页关联推荐** — 用户浏览某篇文章或商品时，下方展示相关推荐
4. **对话中推荐** — AI 回答用户问题后，附带 1-2 条相关非遗内容推荐

## 行为数据

系统利用以下用户行为了解用户偏好：

- 浏览过的商品品类（剪纸、陶艺、刺绣、竹编等）
- 预约过的工坊类型
- 与 AI 对话中反复询问的话题
- 评论和互动过的文章主题
- 购买过的商品

## 推荐场景

### 首页个性推荐区
根据用户偏好展示精选非遗内容（文章 + 商品 + 活动）

### 详情页"你可能也感兴趣"
文章/商品/传承人详情页底部的相关内容推荐

### AI 对话中的内容推荐
AI 回答结束后附带 1-2 条相关内容链接

## 验收标准

- [ ] 有行为历史的用户看到个性化推荐，内容与其历史偏好相关
- [ ] 新用户展示热门内容
- [ ] 推荐内容随用户新行为而更新
- [ ] 不推荐用户已购买或最近已看过重复内容
- [ ] 推荐内容出现在首页、详情页、AI 回答中三处
