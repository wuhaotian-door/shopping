# 非遗知识库检索

## 功能概述

用户用自然语言提问非遗相关问题，系统从平台非遗知识内容中找到最相关的信息并返回，同时标注信息来源。

## 用户场景

1. **非遗知识查询** — 用户输入"苏绣有什么特点"，返回和苏绣特点相关的内容片段
2. **传承人信息查询** — 用户输入"苏州有哪些刺绣传承人"，返回匹配的传承人信息
3. **非遗项目查询** — 用户输入"最近有什么陶艺体验活动"，返回相关非遗项目
4. **模糊探索** — 用户输入"我想学一门传统手工艺，有什么推荐"，返回引导性内容

## 知识范围

系统检索范围覆盖平台内的非遗相关内容，包括但不限于：

- 非遗知识文章
- 传承人档案信息
- 非遗项目/活动信息

## 使用流程

1. 用户在搜索框输入自然语言问题
2. 系统理解问题语义，从知识内容中找到最相关的条目
3. 返回结果列表，每条包含：
   - 内容摘要（匹配的片段）
   - 来源类型（文章 / 传承人 / 项目）
   - 来源标题
   - 点击可跳转到详情页

## 验收标准

- [ ] 输入非遗相关问题，返回前 5 条最相关结果，响应时间不超过 2 秒
- [ ] 每条结果标注来源出处
- [ ] 检索结果与问题语义相关，非简单关键词匹配
- [ ] 新增知识内容后可被检索到
- [ ] 无相关知识时返回空列表，不返回无关内容
