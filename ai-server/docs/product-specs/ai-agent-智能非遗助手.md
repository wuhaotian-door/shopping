# AI 智能非遗助手

## 功能概述

用户与一个 AI 智能助手自由对话。助手根据对话内容自主判断需要做什么——普通闲聊、查非遗资料、推荐内容——像真人一样自然交流。

助手能获取平台各类信息（非遗知识文章、传承人、项目活动、商品），需要时自动检索，回答中标注来源。初次对话的新用户推荐热门内容，老用户根据历史偏好推荐。

## 用户场景

1. **闲聊** — 用户说"你好"，助手正常打招呼；用户问"今天适合学什么非遗"，助手结合用户偏好给出建议
2. **查资料** — 用户问"苏绣有什么特点"，助手自动从知识库检索苏绣相关内容，标注来源后回答
3. **问传承人** — 用户问"苏州有哪些刺绣传承人"，助手检索传承人信息回答
4. **找活动** — 用户问"最近有什么陶艺体验活动"，助手检索项目活动信息
5. **推荐** — 用户说"推荐一些适合新手学的非遗"，助手根据用户偏好和热门内容推荐
6. **连续对话** — 用户先问"蜀绣是什么"，再问"它有哪些针法"，助手能理解"它"指蜀绣
7. **会话复用** — 关闭页面后回来，历史对话仍在，可继续上次话题

## 使用流程

1. 用户进入对话页面，自动恢复上次会话（或创建新会话）
2. 用户输入消息
3. 助手逐字输出回答（流式渲染）
4. 助手自主决定是否查资料——需要时自动检索，结果标注来源
5. 侧栏可切换/删除/新建会话

## 验收标准

- [ ] 助手能根据用户输入自主判断：直接回答 / 检索知识 / 推荐内容
- [ ] 回答基于检索到的真实信息，标注来源
- [ ] 流式逐字输出，3 秒内开始响应
- [ ] 多轮对话能理解上下文（指代消解、话题延续）
- [ ] 刷新页面后对话不丢失
- [ ] 支持新建、切换、删除会话
