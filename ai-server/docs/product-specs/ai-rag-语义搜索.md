# 语义搜索

## 功能概述

将平台搜索能力从关键词匹配升级为语义理解。用户用日常口语表达搜索意图，系统理解含义后跨多种内容类型返回综合结果。

## 用户场景

1. **自然语言搜索** — 用户搜索"学刺绣去哪找老师"，返回刺绣类传承人信息，而非仅标题含"刺绣"的文章
2. **跨类型搜索** — 用户搜索"紫砂壶"，同时返回紫砂知识文章、紫砂传承人、紫砂文创商品
3. **模糊意图搜索** — 用户搜索"适合送长辈的非遗礼物"，返回文创商品推荐
4. **无结果处理** — 用户搜索的内容平台暂无相关数据时，给出友好提示和热门内容引导

## 搜索范围

搜索覆盖平台全部公开内容：

- 非遗知识文章
- 传承人信息
- 非遗项目/活动
- 文创商品

## 使用流程

1. 用户在任意页面的搜索框输入查询词
2. 系统理解查询意图，跨文章、传承人、项目、商品四类内容检索
3. 结果按相关度混合排序展示，不同类型用不同卡片样式区分
4. 用户可按类型标签筛选（只看文章 / 只看传承人 / 只看商品 / 只看项目）
5. 点击任意结果跳转到对应详情页

## 验收标准

- [ ] 口语化查询"学刺绣去哪找老师"能返回刺绣类传承人结果
- [ ] 搜索结果跨内容类型呈现
- [ ] 支持按类型筛选
- [ ] 响应时间不超过 2 秒
- [ ] 无结果时展示友好提示，而非空白页
