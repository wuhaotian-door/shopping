# AI 智能对话

## 功能概述

用户以对话方式与 AI 助手交流非遗知识。AI 能理解上下文连续对话，回答基于平台真实知识内容。支持多会话管理。

## 用户场景

1. **知识学习** — 用户与 AI 连续问答深入了解某项非遗技艺，AI 记住之前聊过的内容
2. **游客咨询** — 游客询问"来苏州有什么非遗可以体验"，AI 结合本地传承人和项目信息回答
3. **会话复用** — 用户关闭页面后再次打开，历史对话仍在，可继续上次话题
4. **会话管理** — 用户可新建会话开始新话题、在不同会话间切换、删除不需要的会话

## 使用流程

1. 用户进入智能问答页面，系统自动创建或恢复上次会话
2. 用户输入问题并发送
3. AI 实时逐字输出回答
4. 用户可继续追问，AI 结合上下文回答
5. 侧栏展示历史会话列表，点击可切换
6. 用户可新建会话或删除旧会话

## 验收标准

- [ ] 同一会话内的多轮对话，AI 能结合上文理解用户意图
- [ ] 回答内容来自平台知识，不编造不存在的信息
- [ ] 逐字流式输出，从发送到开始显示回答不超过 3 秒
- [ ] 对话记录在刷新页面或重新打开后不丢失
- [ ] 支持新建、切换、删除会话
- [ ] 前端对话界面完整可用
