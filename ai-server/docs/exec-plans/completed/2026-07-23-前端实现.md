# AI 服务前端实现

## 目标

在 `frontend/` (Vue 3) 项目中实现 AI 对话、语义搜索、个性推荐的完整前端。

## 步骤

1. Vite 代理配置 — `/ai` → `localhost:8000`
2. API 模块 — `src/api/ai.ts`
3. AI 对话页 — 改造 `RagView.vue`（SSE 流式 + 会话管理 + 模式切换）
4. 语义搜索页 — `AiSearchView.vue`
5. 推荐组件 — `AiRecommendPanel.vue`
6. 路由更新

## 影响范围
